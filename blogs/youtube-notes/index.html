The Rewatch Tax

You know the feeling: a 40-minute tutorial definitely contained the one command you need, and now you're scrubbing through the timeline like a detective, watching at 2x speed, hoping to catch it.

Video is a terrible format for retrieval. Text you can search, skim, and quote — video you can only rewatch. Every exam season, every late-night debugging session, I paid this rewatch tax over and over. So I built a toll booth skip: a tool that converts any YouTube video into clean, searchable text in seconds.

Paste Link, Get Transcript

The flow is deliberately boring — boring is reliable:

  1. Paste any YouTube link into the box and hit process.
  2. Download a clean, premium-formatted transcript as a .txt file — no timestamps cluttering every line, no auto-generated gibberish.
  3. Search it like any document: Ctrl + F the exact answer instead of rewatching 40 minutes.

It runs as a lightweight edge utility, so there's nothing to install and no account to create. Link in, text out.

From Transcript to Notes & MCQs

A raw transcript is useful; structured notes are transformative. That's why the tool ships with one-click AI prompts built in:

  • Copy Notes Prompt: grabs a carefully written prompt that turns the transcript into organized study notes — headings, key points, summaries — when pasted into any AI assistant alongside the text.
  • Copy MCQ Prompt: grabs a second prompt that converts the same transcript into a multiple-choice quiz, so you can test yourself on exactly what the video taught.
The clever part isn't fetching text — it's packaging the next step. Extraction plus the right prompt beats extraction alone.

Watch a lecture once, walk away with searchable text, revision notes, and a self-test. That's the whole pipeline.
