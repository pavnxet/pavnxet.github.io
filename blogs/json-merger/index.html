The Endless Copy-Paste Problem

Making quizzes usually means ending up with ten different files scattered everywhere — one per chapter, one per topic, one that a friend sent you at midnight.

Every time I wanted a single master quiz, the ritual was the same: open each file, copy the text, paste it into one big file, and pray I didn't break the formatting somewhere in the middle. Doing this by hand is incredibly tedious and embarrassingly error-prone — one missed bracket and the whole file refuses to load.

Computers are supposed to do boring repetitive merging. So I made one do it.

How the Tool Works

I built a small utility called Quiz JSON Merger that does all the heavy lifting automatically. It meets you wherever you already are — desktop or phone:

  • Drag & drop in the browser: Drop all your separate quiz files into the web page and it spits out a single combined file instantly. Nothing uploads anywhere permanent; the merge happens and you download the result.
  • Telegram bot for phone life: Because I do a lot from my phone, I wired the same merger to a chat bot. Forward your quiz files to it, send one quick command, and it sends the merged file right back to you.

Same engine, two doors. Use the browser at your desk, the bot on the bus.

The Part That Kept Breaking

Getting the Telegram bot to remember files was a genuine headache. Telegram treats every message as a completely isolated event — the bot would cheerfully forget your first file the moment you sent the second one.

The fix was a temporary holding area: when you send files, the bot parks them in a short-lived Cloudflare-backed store tied to your chat, and only merges everything when you explicitly say you're done. Send three files across three messages, say merge, get one master file back. Nothing lingers longer than it needs to.

Stateless platforms force you to design state explicitly — and explicit state is almost always cleaner state.
