The PDF Nobody Can Search

When the Rajasthan Staff Selection Board declared the Clerk Grade-2 / Junior Assistant 2026 written result, the provisional pass list arrived the way these things always arrive: as a giant PDF dump — thousands of pages of roll numbers and names, assembled for printing, not for finding.

If your name is anywhere in there, good luck. Phone PDF readers choke on files this size, Ctrl + F crawls page by page, and every anxious candidate in Rajasthan ends up scrolling the same endless columns. I built the 3rd Grade result searcher for exactly this pain — and the LDC list, at nearly a quarter-million names, deserved the same treatment.

241,690 Candidates, One File

The source is the official LDC_Full_Result.pdf, structured into two annexures. I converted the whole thing into structured data:

  • Annexure-1 (Non-Scheduled Area): 226,234 candidates.
  • Annexure-2 (Scheduled Area / TSP): 15,456 candidates.
  • Per candidate: roll number, candidate name, father name, mother name, gender, category, and sub-category.

Here's the fun engineering detail: as raw JSON that's roughly 46MB — far too heavy to ship to a phone browser. Gzip-compressed, it collapses to about 7.6MB, embedded directly in a single HTML file. The portal decompresses it client-side with a progress splash screen, so by the time the search box appears, all 241,690 records are already sitting in memory. No server, no database, no API to keep alive — the whole portal is one file on Vercel that works offline after first load.

Search Like a Human Thinks

Nobody remembers their exact roll number under stress — but everyone remembers names. So the search works the way anxious humans actually query:

  • Name, father name, or mother name: type any of them (Hindi-first interface) and matches appear instantly — mother's name included, which most portals skip and which resolves countless same-name collisions.
  • Roll number: exact lookup when you have the admit card handy.
  • Region, category & gender filters: narrow by Non-Scheduled vs TSP area, reservation category, and gender instead of drowning in thousands of same-name rows.
  • Live record badge & Telegram channel: the header shows the dataset size at a glance, and updates ride along on the linked Telegram channel.
A result portal is judged on one metric: seconds from panic to answer. Everything in this design serves that number.
